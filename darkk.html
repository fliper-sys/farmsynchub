A dark theme built on real elevation, not one grey

Right now the app leans on flat near-black surfaces and pure white text, which is why the procurement/sales sheets read as jarring pure-white flashes and why cards feel either too plain or too busy. This proposes a proper 4-level elevation ladder, a softened text scale, and a redesigned card pattern that won't break on a small phone.

1 · Elevation ladder

Each level is a controlled step lighter than the one below — never one flat grey reused everywhere. Background stays near-black for OLED battery savings; sheets/dialogs/bottom nav sit on level 2–3.

5 · Flutter techniques behind the fix

What each redesign change actually maps to in code.

📐
Responsive chip row, not Wrap
Swap the Wrap of 8 chips for a horizontally-scrolling ListView capped at 3 chips + a "+N more" chip. Width-independent — never wraps to 4 lines on a small phone again.
🖼️
Decode images at display size
Thumbnails currently decode the full uploaded photo. Add cacheWidth/cacheHeight to every Image.memory thumbnail — same visual result, a fraction of the memory and jank on lower-end phones.
🧱
Material 3 card variants
Use Card.filled with an explicit CardTheme (12dp radius, surfaceTintColor: transparent) so cards stay flat and match this palette instead of Material 3's default purple-ish elevation tint.
🎬
Hero transitions
Wrap the crop/livestock thumbnail in a Hero widget so tapping into the detail screen animates the image growing into place — cheap, and it's the single highest-perceived-polish animation for list → detail flows.
✨
Implicit animations for state
AnimatedContainer/AnimatedSize on checkbox toggles, the progress bar fill, and section expand/collapse — no controller boilerplate needed, and it's what makes the UI feel alive instead of snapping between states.
📱
LayoutBuilder for true adaptivity
Below ~360dp, stack the thumbnail above the title instead of beside it. LayoutBuilder makes this a per-card decision instead of hoping Expanded saves you.
